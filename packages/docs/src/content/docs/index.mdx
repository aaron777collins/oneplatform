## What is OnePlatform?

OnePlatform is a self-hosted, API-first data platform built for teams that need to
connect multiple data sources, define a shared data ontology, and expose that data
through apps and plugins — all behind a single authenticated gateway.

<CardGrid>
  <Card title="9 Microservices" icon="puzzle">
    Gateway, Auth, Ingestion, Ontology, Pipeline, Execution, App, Logging, and Plugin
    services — each with its own OpenAPI specification.
  </Card>
  <Card title="3 SDKs" icon="seti:javascript">
    `@oneplatform/sdk` for server-side automation, `@oneplatform/app-sdk` for React apps,
    and `@oneplatform/plugin-sdk` for platform extensions.
  </Card>
  <Card title="CLI" icon="terminal">
    The `op` CLI covers every platform operation — from bootstrapping a fresh install to
    deploying apps and managing plugins.
  </Card>
  <Card title="Extensible" icon="add-document">
    Plugins hook into the ingestion, pipeline, and execution lifecycle. Apps run inside
    the platform's sandboxed BFF environment.
  </Card>
</CardGrid>
