4. IMPORTANT: CHANGE DEFAULT CREDENTIALS

If you installed without a pre-existing secret (existingSecret=""), the
chart created a Secret with the placeholder passwords from values.yaml.
Rotate ALL credentials before exposing this deployment externally:

  - secrets.postgresPassword
  - secrets.appDbPassword
  - secrets.redisPassword
  - secrets.minioRootPassword
  - secrets.jwtPrivateKey / jwtPublicKey
  - grafana.adminPassword

For production, pre-create a Kubernetes Secret containing all keys and
set existingSecret=<name> to prevent the chart from managing credentials.

Quick horizontal scale of a stateless service:
  kubectl scale deployment {{ include "oneplatform.fullname" . }}-gateway \
    -n {{ .Release.Namespace }} --replicas=3

Do NOT scale the ontology service while schema migrations are running.
Advisory locks serialize migration runs; two replicas racing a migration
will block until one completes.
