# `op profile`

Multi-environment profile management

### `add`

Create a new profile

**Usage:** `add [options] <name>`

**Arguments:**

- `<name>` — Profile name

**Options:**

- `--platform <url>` — Platform base URL
- `--key <api-key>` — API key to store encrypted


---

### `list`

List all profiles

**Usage:** `list [options]`


---

### `use`

Set the active profile

**Usage:** `use [options] <name>`

**Arguments:**

- `<name>` — Profile name to activate


---

### `remove`

Remove a profile

**Usage:** `remove [options] <name>`

**Arguments:**

- `<name>` — Profile name to remove
